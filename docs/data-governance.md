# 数据处理与访问

仅本地、受控演示，默认 CN；不接收真实完整病历和身份资料。所有 JSON 入口先作识别与拒收，PDF 文本中的数字证件/账户/手机号遮蔽后才保存在加密会话内。规则检测有漏判可能，使用者应主动删除不必要资料。

会话 bearer token 为256位随机数，只发一次；服务器存 SHA-256，浏览器 sessionStorage 可恢复当前标签页。token 不能访问其他会话。页面采用 CSP、同源校验、Helmet、限流；仅静态白名单文件可访问。管理员仅本机回环 + ADMIN_API_TOKEN。

必要字段以 AES-256-GCM 加密，随机12字节 nonce，16字节 tag。无稳定密钥只使用进程内数据库；会话到期后不能访问。生产数据库、.env、备份和原始附件禁止入库 Git。PDF 原始数据仅短暂在内存，解析完成清零，不写上传目录。

external_llm、sensitive_data、handoff 同意分目的记录，可撤回。sensitive_data 同意不启用完整病历上传。未成年人和健康资料不传外部模型。真实模型测试未执行，默认全部离线规则；不得将 Mock 指标当付费模型成本或专业正确率。

删除会话级联删除报告、工单和加密资料，审计仅留匿名哈希、时间与事件类型。历史离线备份不能承诺即时擦除；保留及清理策略须正式上线前批准。到期访问失效不等于物理擦除，需运维定期清理。

工单只有 PENDING_UNASSIGNED，没有真实人员或SLA，不向任何外部渠道发消息。不存在“已成功转交”的承诺。
